# Security Policy

## Supported versions

Only the latest release of AlleviatedBackpacks receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems (for example a way for a client to duplicate or read items it should not reach on a server). Report them privately through [GitHub's private vulnerability reporting](https://github.com/LiteLDev/AlleviatedBackpacks/security/advisories/new) instead. You should get a response within a week. Once a fix is released, the issue is disclosed.
